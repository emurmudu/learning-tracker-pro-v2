# LearnFlow — Learning Tracker Pro v2

This v2 turns the original tracker into a portfolio-quality learning productivity product.

## New product features

- Premium dashboard / learning workspace
- Focus timer with 25/50/90 minute presets
- Monthly goal progress
- Achievement badges
- Searchable learning records
- Subject filters
- Improved visual hierarchy
- Responsive professional sidebar
- Dark mode
- Learning momentum chart
- Subject-focus chart
- Calendar
- Monthly reports and export
- Firebase authentication
- MongoDB cloud data
- Secure per-user API access

## Monthly goal

Set this in the browser console if desired:

```js
localStorage.setItem("monthlyGoal", "40")
```

The default is 20 hours.

## Run

The setup is the same as v1:

```bash
cd server
npm install
npm run dev
```

and:

```bash
cd client
npm install
npm run dev
```

Read `README.md` and `SETUP-CHECKLIST.md` for Firebase and MongoDB configuration.
